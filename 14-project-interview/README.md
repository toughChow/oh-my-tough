# 14｜项目与面试表达

## 必备材料

- [ ] 30 秒自我介绍
- [ ] 3 分钟自我介绍
- [ ] 两个核心项目讲稿
- [ ] 一个复杂技术难点
- [ ] 一个线上故障复盘
- [ ] 一个跨团队协作故事
- [ ] 一个失败及改进故事
- [ ] 离职原因与职业规划

## 项目表达结构

采用“背景—职责—问题—方案—权衡—结果—复盘”。回答中明确个人贡献，并尽量提供延迟、吞吐、准确率、召回率、错误率或成本等数据。

## AI 全栈主项目建议

建设一个可评测的企业知识库，覆盖：

- 文档解析与切分
- 混合检索与重排
- 引用溯源和权限控制
- 流式回答和会话管理
- 离线评测与用户反馈
- 调用追踪、成本监控和部署

该项目可同时承载前端、后端、数据库、RAG、系统设计和工程化面试问题。
