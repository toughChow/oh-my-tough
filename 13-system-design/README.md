# 13｜系统设计

## 通用方法

1. 澄清功能、规模和非功能需求。
2. 估算 QPS、存储和带宽。
3. 设计 API、数据模型和核心链路。
4. 讨论扩展、一致性、容错、安全与观测。
5. 找出瓶颈并说明方案取舍。
